## Introdução
Signa é um projeto de desenvolvimento multiplataforma, com o intuito de ser uma ferramenta capaz de diminuir a barreira linguística entre os estudantes que possuem problemas de comunicação por causa de surdez com seus professores, de maneira rápida fácil e tecnológica. Temos como fundamento, a facilidade de acesso e porte de elementos tecnológicos móveis, como os celulares. A partir disso, temos que modelos de Inteligência Artificial, principalmente no campo da visão computacional, podem ser usados com o intuito de facilitar as metodologias de aprendizado propostas presentes.
